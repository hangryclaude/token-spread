# Auditor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A read-only, metadata-only auditor that ingests LLM usage metadata from Anthropic, OpenAI and Azure, detects every strict-identity savings opportunity, and reports the blended saving computed from the customer's own measured hit rate.

**Architecture:** Extends the existing pure core (`UsageEvent` → `costOfEvent` → `computeMetrics`) with a provider-agnostic event shape, a detector registry where each detector emits findings carrying an evidence class, and a blended-savings calculator that multiplies multipliers per token category instead of summing headline percentages. `cli.ts` remains the only I/O boundary. Prompt content never enters the process.

**Tech Stack:** Bun + TypeScript. `bun test`. Integer micro-cents, no floating-point money. No new runtime dependencies.

## Global Constraints

- **No prompt content, ever.** Every event carries counts and metadata only. The existing content-leak test in `tests/importer.test.ts` must keep passing and be extended to each new importer.
- **Integer micro-cents.** All money is `number` micro-cents (1e-6 cent). No float arithmetic in any pricing path.
- **Pure core.** Everything except `cli.ts` and the importers' file reads is pure: no clock, no network, no global mutable state.
- **Savings multiply, never add.** Any code path that sums two savings percentages is a bug.
- **Evidence class on every finding.** One of `PASS_ABSOLUTE`, `PASS_METADATA`, `PASS_SCHEDULING`, `PASS_REPLAY`, `CONTRACTUAL_ONLY`. A finding without one must not compile.
- **Launch providers: Anthropic, OpenAI, Azure.** Gemini is excluded — its implicit caching is default-on with no documented behaviour-invariance guarantee. Do not add a Gemini importer.
- **Never emit an unsourced percentage.** A savings figure is either computed from the customer's own data or marked `UNQUANTIFIED`.
- Source of truth for technique semantics: `docs/research/2026-08-10-strict-identity-register.md`.

```ts
  "claude-opus-5": 512, "claude-fable-5": 512, "claude-mythos-5": 512,
  "claude-opus-4-8": 1024, "claude-sonnet-5": 1024,
```

```ts
import type { Finding } from "../findings";
import type { EvidenceClass } from "../evidence";
import type { UsageEvent } from "../types";
import type { Metrics } from "../metrics";
import type { RateCard } from "../rates";

export interface Detector {
  id: string;
  evidence: EvidenceClass;
  run(events: UsageEvent[], metrics: Metrics, card: RateCard): Finding[];
}

/** One broken detector must not cost the customer the whole report. */
export function runDetectors(
  events: UsageEvent[], metrics: Metrics, card: RateCard, detectors: Detector[],
): Finding[] {
  const out: Finding[] = [];
  for (const d of detectors) {
    try { out.push(...d.run(events, metrics, card)); }
    catch { /* a detector's bug is not a reporting failure */ }
  }
  return out.sort((a, b) => (b.recoverableMicroCents ?? 0) - (a.recoverableMicroCents ?? 0));
}
```

```ts
import type { Detector } from "./registry";
import type { Finding } from "../findings";

/** We cannot see prompts, so we cannot know the true repeated-prefix share.
 *  Report the ceiling and label it structural — never quote it as an expected saving. */
const CEILING_MULTIPLIER = 0.9;   // cache reads bill at 0.1x base input

export const cacheDisabledDetector: Detector = {
  id: "cache-disabled",
  evidence: "PASS_METADATA",
  run(events, _metrics, card) {
    const byModel = new Map<string, UsageEvent[]>();
    for (const e of events) {
      const list = byModel.get(e.model) ?? [];
      list.push(e);
      byModel.set(e.model, list);
    }

    const out: Finding[] = [];
    for (const [model, evs] of byModel) {
      if (evs.length < 2) continue;                                  // no reuse possible
      const usedCache = evs.some(e => e.cacheReadTokens > 0 || e.cacheCreationTokens > 0);
      if (usedCache) continue;

      const rate = card.rates[model];
      if (!rate) continue;                                           // never guess an unknown model
      const inputMicroCents = evs.reduce((n, e) => n + e.inputTokens * rate.input, 0);

      out.push({
        detectorId: "cache-disabled",
        evidence: "PASS_METADATA",
        title: `${model}: prompt caching never engaged across ${evs.length} requests`,
        detail:
          `No request on this model returned cache_read_input_tokens or ` +
          `cache_creation_input_tokens. Adding a cache_control breakpoint is a metadata-only ` +
          `change — the model reads the same bytes. Ceiling shown assumes a fully repeated ` +
          `prefix; the real figure depends on how much of the prompt actually repeats.`,
        recoverableMicroCents: Math.floor(inputMicroCents * CEILING_MULTIPLIER),
        confidence: "structural",
      });
    }
    return out;
  },
};
```

```ts
export const belowMinimumDetector: Detector = {
  id: "below-minimum-prefix",
  evidence: "PASS_METADATA",
  run(events, _m, _card) {
    const out: Finding[] = [];
    for (const e of events) {
      const min = minimumCacheableTokens(e.model);
      if (min === null) continue;
      if (e.cacheCreationTokens > 0 || e.cacheReadTokens > 0) continue;
      if (e.inputTokens >= min) continue;

        detectorId: "below-minimum-prefix",
        evidence: "PASS_METADATA",
```

```ts
export const ttlMismatchDetector: Detector = {
  id: "ttl-downgrade",
  evidence: "PASS_METADATA",
  run(events) {
    const bad = events.filter(e =>
      e.ttlRequested !== null && e.ttlGranted !== null && e.ttlRequested !== e.ttlGranted);
    if (bad.length === 0) return [];
```

```ts
const RACE_WINDOW_MS = 250;

/** A cache entry is readable only after the first response begins streaming. N parallel
 *  requests sharing a prefix therefore all write instead of 1 write + (N-1) reads. */
export const concurrencyRaceDetector: Detector = {
  id: "concurrency-race",
  evidence: "PASS_SCHEDULING",
  run(events, _m, card) {
    const byHash = new Map<string, UsageEvent[]>();
    for (const e of events) {
      if (!e.requestHash || e.cacheCreationTokens === 0) continue;
      const l = byHash.get(e.requestHash) ?? [];
      l.push(e);
      byHash.set(e.requestHash, l);
    }

    const out: Finding[] = [];
    for (const [hash, evs] of byHash) {
      if (evs.length < 2) continue;
      const sorted = [...evs].sort((a, b) => Date.parse(a.ts) - Date.parse(b.ts));
      const first = Date.parse(sorted[0].ts);
      const raced = sorted.filter(e => Date.parse(e.ts) - first < RACE_WINDOW_MS);
      if (raced.length < 2) continue;

      // Every writer after the first should have been a read at 0.1x.
      const wasted = raced.slice(1).reduce((n, e) => {
        const rate = card.rates[e.model];
        if (!rate) return n;
        return n + e.cacheCreationTokens * (rate.cacheWrite - rate.cacheRead);
      }, 0);

      out.push({
        detectorId: "concurrency-race",
```

```ts
import { createHash } from "node:crypto";

/** Fields that are routing or caching metadata: the model never reads them as content.
 *  Every addition to this set widens the guarantee and needs a documented justification
 *  in docs/specs/2026-08-10-receipt-threat-model.md. */
const METADATA_FIELDS = new Set(["cache_control", "prompt_cache_key", "cache_ttl"]);

/** Strips metadata fields, preserving array order — order IS content. Object key order is
 *  not content on the wire, so keys are sorted to make the hash serialization-stable. */
export function modelVisibleProjection(value: unknown): unknown {
  if (Array.isArray(value)) return value.map(modelVisibleProjection);
  if (value === null || typeof value !== "object") return value;
  const out: Record<string, unknown> = {};
  for (const key of Object.keys(value as Record<string, unknown>).sort()) {
    if (METADATA_FIELDS.has(key)) continue;
    out[key] = modelVisibleProjection((value as Record<string, unknown>)[key]);
  }
  return out;
}

export function canonicalHash(request: unknown): string {
  return createHash("sha256")
    .update(JSON.stringify(modelVisibleProjection(request)))
    .digest("hex");
}
```

- [ ] **Step 5: Write the receipt threat model**

1. **The canonical model-visible projection** — the `METADATA_FIELDS` set, why each member is metadata, and the rule that array order is content while object key order is not.
2. **Hashing and canonicalization** — SHA-256 over `JSON.stringify` of the projection; the stability requirement; how a future JSON canonicalization change would be versioned rather than silently applied.
3. **Signing and key rotation** — Ed25519 detached signature over the receipt body; key id in every receipt; rotation cadence; how a customer verifies a receipt signed under a retired key.
4. **Excluded transport fields** — headers, timestamps, retry counters and connection metadata are outside the projection and outside the signature's identity claim.
5. **Offline verification** — the exact steps a customer runs, with no network access and no trust in us, to check that the projection hash before and after our transform are equal.
6. **What the receipt proves** — that we did not alter one byte the model reads; that a replayed response hash-matches a stored one.
7. **What it does not prove** — that the provider would have returned identical bytes without us. Hosted inference is not bit-reproducible: GPU reduction order varies with concurrent batch composition, and no provider exposes deterministic-kernel attestation. State this in the document rather than letting a customer infer a stronger claim.

```ts
export interface TokenCategory {
  label: string;
  tokens: number;
  baseMicroCentsPerToken: number;
  /** Every multiplier applying to this category. Write premiums are > 1.0. */
  multipliers: number[];
}

export interface BlendedResult {
  baselineMicroCents: number;
  effectiveMicroCents: number;
  /** effective / baseline. Below 1.0 is a saving; above 1.0 is a net cost. */
  effectiveMultiplier: number;
  savingsMicroCents: number;
  byCategory: { label: string; multiplier: number; microCents: number }[];
}

export function blendedSavings(categories: TokenCategory[]): BlendedResult {
  let baseline = 0, effective = 0;
  const byCategory: BlendedResult["byCategory"] = [];

  for (const c of categories) {
    const base = c.tokens * c.baseMicroCentsPerToken;
    const m = c.multipliers.reduce((acc, x) => acc * x, 1);
    const cost = Math.round(base * m);
    baseline += base;
    effective += cost;
    byCategory.push({ label: c.label, multiplier: m, microCents: cost });
  }

  return {
    baselineMicroCents: baseline,
    effectiveMicroCents: effective,
    effectiveMultiplier: baseline === 0 ? 1 : effective / baseline,
    savingsMicroCents: baseline - effective,
    byCategory,
  };
}
```

**Spec coverage.** Families A–F of the register map to tasks: A → 4, 6, 7; B → deferred to the
Optimizer (the Auditor only detects); C → 7 (`concurrencyRace`); D → 8, 9; E → 9; F → not
detectable from usage metadata, so it is reported as a checklist rather than a detector — noted
here as a deliberate omission, not a gap. Family G ships as the `optIn` bucket in Task 13.

**Interface consistency.** `Detector` is defined once in Task 5 and consumed unchanged in 6, 7
and 9. `Finding` carries `recoverableMicroCents: number | null` everywhere; the report sums only
`confidence: "measured"` findings. `canonicalHash` from Task 8 is what fills `UsageEvent.requestHash`
from Task 3 — the Auditor cannot compute it from a transcript it did not intercept, so
`requestHash` stays `null` for the Claude Code importer and the two detectors that need it simply
do not fire. That is correct behaviour, not a defect, and Task 9's tests supply the hash directly.

**Known gap.** The Optimizer, the signed receipt implementation, and stable-prefix discovery are
deliberately not in this plan. They need their own plan once Task 14 and 15 report, and they are
the point at which the product moves into the request path and inherits the security review this
plan's metadata-only design avoids.
