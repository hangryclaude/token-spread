# Sweep 15 — the 2026 surface

**309 entries · 67 pass · 84 on the provider's word · 104 rejected · 54 unresolved.**

Thirty-five new entries, ids 274–308. Five pass.

Sweep 14 mined GitHub; this sweep mined what 2026 changed: the Anthropic SDK/API surface
(beta headers, Files API, token-efficient tool use), cloud release notes (Bedrock, Vertex,
Azure Foundry), gateway layers nobody had opened (Portkey, Cloudflare, Kong, Bifrost),
a second pass over cost-observability tools, practitioner war stories, Claude Code's own
cost surface, batch-pipeline libraries, and the pricing/terms pages themselves. Eight
miners, verbatim quotes only; a dedup gate against all 274 existing entries; adjudication
with mandatory re-fetch; **two refuters per claimed pass** — evidence lens and mechanism
lens, either sufficient to lower a verdict; and a completeness critic whose thirty findings
shaped what actually landed.

The five drops at landing, named so they cannot be quietly re-mined: the
anthropic-sdk-python #1451 cache-miss bug (corroborates id 255 — same server-side fix,
same close date), Bedrock Cross-Region for OpenAI models (id 101's mechanism), the
`service_tier` request-field semantics (sharpens id 123), the Message Batch
`processing_status` enum (evidence for ids 303–305, not a technique), and the OpenClaw
webhook spiral (the single-source spend-anecdote class id 161 exists to foreclose).

Where the five passes cluster repeats sweep 14's lesson so exactly it is now doctrine:
**every pass is a correction to an instrument.** Two Datadog LLM Observability double-span
overcounts (~2.2x on LangChain+Anthropic, 2x on LangChain+google_genai), two OpenLLMetry
accounting bugs (streamed output tokens double-accumulated; cache-token constants that do
not exist), and one Bifrost client-side SSE duplication. Nothing on the wire changes; the
bill was simply read wrong. The savings that survive the bar are corrections to
instruments, sweep after sweep.

The commonest downgrade was again docs-sentence-doing-PASS-work: four Claude Code entries
(--max-budget-usd, the /usage fix, both subagent-limit variables) rested entirely on
Anthropic's own docs or changelog and fell to CONTRACTUAL_ONLY or FAIL under refuters who
checked what the entry had not — one found that a subagent-limit doc describes injecting a
"don't retry" directive, which is model-facing content and therefore a changed product.
BatchLLM's crash-resume replay fell from PASS_REPLAY to FAIL on a code-verified gap: its
checkpoint fingerprint excludes multi-field template variables, so a resume can silently
replay a stale answer against a changed prompt — a byte-identity guarantee that is not one.

Two entries deserve a spotlight for the money involved. **Id 274**: Claude Sonnet 5's new
tokenizer bills approximately 30% more tokens than Sonnet 4.6 for identical text —
Anthropic's own pricing page says so in a footnote, and anyone budgeting a migration off
the sticker price alone will meet the difference on an invoice. FAIL as a technique (the
model reads different tokens by construction), permanent as a trap. **Id 284**: Portkey
silently drops `cache_control` when routing Anthropic through Vertex, forfeiting the
entire cache discount for anyone on that path.

`↻` marks an entry whose verdict changed under challenge. Seven of thirty-five did.
