Savings Report — the read-only first slice

Reads usage that already happened and produces one auditable claim: here is what your traffic costs today, and what it would cost under caching and routing you're not yet using. No gateway, no keys, nothing at risk.

date 2026-08-08 stack TypeScript · bun 1.3.14 risk read-only

~/dev/token-spread/docs/specs/2026-08-08-savings-report-design.md · branch spec/savings-report · local only

1Purpose

Produce a current-cost vs. projected-cost report from sanitized usage records:

  1. Recompute what the observed traffic actually cost, from real per-request token counts × a dated rate card. Must reconcile against the real bill.
  2. Measure the observed cache-hit rate — a hard number, no assumption.
  3. Simulate two savings levers, each under an explicit, user-set assumption: routing routine work to a cheaper model, and raising the cache-hit rate.
  4. Emit an auditable report: every figure traces back to the source rows and the stated assumptions; same input always yields the same report.
The single claim it proves

"X% of your input is already cache-eligible but served fresh, and Y% of your requests look routable to a cheaper model. Together that's $Z/month of headroom in spend you're already making." One hard number, two clearly-labelled projections.

What it is not (YAGNI)

  • Not a gateway. Never serves a request or issues a key.
  • Never calls the Messages API, never writes to any Anthropic endpoint.
  • Never reads prompt or response content — only token-count metadata.
  • No web UI in this slice. CLI + JSON report first.

2Inputs — two importers, one output type

Ships A first; B is specced behind the same interface so it lands second without touching downstream code.

ImporterSourceWhy the order
A · Claude Code Local JSONL at ~/.claude/projects/*/*.jsonl. Reads message.model + message.usage.* + timestamp from assistant records only. No org, no key, no network. Proves the premise on your own machine.
B · Admin API GET /v1/organizations/usage_report/messages with an admin key. Content-free by construction. Authoritative vs. the bill, but Enterprise-only — so it's second.
Content is never touched

message.content is never read. The importer extracts only the token-count fields and discards the rest of the line in the same pass — content never enters a record, memory beyond the parse, or any saved file.

3Canonical schema

Every importer emits UsageRecord[]. There is no content field, by design.

interface UsageRecord {
  ts: string;                    // ISO 8601
  source: "claude_code" | "admin_usage_report";
  model: string;                 // canonical model id
  inputTokens: number;           // fresh/uncached input (>= 0)
  cacheReadTokens: number;       // served from cache (>= 0)
  cacheCreationTokens: number;   // cache writes (>= 0)
  outputTokens: number;          // >= 0
  requestId?: string;            // opaque; dedup only
}
  • Unknown model → flagged and excluded from cost math (a skipped bucket). Never priced at $0 or guessed.
  • Negative / non-integer token → rejected into malformed.
  • Duplicate requestId → dropped, counted in deduped.

4Privacy boundaries

Hard constraints, tested — not aspirations:

  • Local by default. Importer A touches only the filesystem. No outbound connection unless B is explicitly invoked with an admin key.
  • No content, ever. A test asserts records carry no keys beyond the schema.
  • Aggregates out. The report contains per-model totals and token counts only. requestId is dedup-only, never emitted.
  • No telemetry. Phones nobody. No crash upload.

5Core calculations

All money in integer cents, never binary float. Rates per-MTok, dated, one source-of-truth module.

Rate card

claude-opus-5     in $5.00  out $25.00
claude-sonnet-5   in $3.00  out $15.00   (standard; intro $2/$10 ends 2026-08-31)
claude-haiku-4-5  in $1.00  out  $5.00
cacheReadMultiplier   = 0.10
cacheWriteMultiplier  = 1.25
capturedAt            = 2026-06-24

Observed cache-hit rate — the hard number

cacheHitRate = cacheReadTokens_total
             / (cacheReadTokens_total + inputTokens_total)

Of the input eligible to be cached (fresh + read), the share actually read from cache. cacheCreationTokens is the write cost and is excluded from the denominator; the report states this inline so the number is never ambiguous.

Routing is a what-if, not a claim

A read-only pass has no per-request difficulty label, so routing savings is an explicit what-if under a stated fraction. Output is a curve over f ∈ {0, .25, .5, .75, 1} — never a single number dressed up as fact. f=0 ⇒ $0 saved (identity check).

6Architecture — small, isolated units

importers/claudeCode.ts   raw JSONL → UsageRecord[]   (strips content; pure)
importers/adminReport.ts  API JSON  → UsageRecord[]   (ships second; same signature)
rates.ts                  dated rate card, single source of truth
metrics.ts                → currentCost, cacheHitRate, byModel   (pure)
simulate.ts               + assumptions → projections            (pure)
report.ts                 → Report object                        (pure)
cli.ts                    the only unit that does I/O

Each unit has one purpose and a typed interface. metrics, simulate, report are fully deterministic — clock and rate-card date are injected, not read ambiently, so the same input yields a byte-identical report.

7Acceptance criteria

#Criterion
1Current cost is exact — matches an independently hand-computed cent value.
2Cache-hit: no cache_read ⇒ 0%; all cache_read ⇒ 100%.
3Routing identity: f=0 ⇒ $0.00; f=1 ⇒ full hand-computed delta.
4Headroom below observed is rejected; = observed ⇒ $0.
5Content never leaks — records carry only schema keys; report JSON contains no planted content substring.
6Bad input is bucketed, not swallowed.
7Determinism — two runs on one fixture, identical JSON.
8No egress in importer A — completes with the network stubbed to throw.

8Validation — synthetic fixtures only

No real transcripts in tests. Each fixture ships a separately hand-computed expected result — so the assertion is checked against a different instrument than the code that produced the number.

9Out of scope for this slice

Gateway, request proxying, key issuance, unattended writes, flat-rate billing, multi-tenant, web UI, non-Anthropic models. Each is a later slice with its own spec. This one earns the right to build those by proving the spread is real, on real data, with nothing at risk.
