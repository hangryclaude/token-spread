Don't take our word for it

The calculator is a model.
This is the measurement.

Anthropic will tell you your own numbers. One command, on your machine, and you have the same file our audit reads — before you've spoken to us.

your machine · nothing leaves it
# 1. Pull your own usage. The admin key never goes anywhere but Anthropic.
curl https://api.anthropic.com/v1/organizations/usage_report/messages \
  -H "anthropic-version: 2023-06-01" \
  -H "x-api-key: $ANTHROPIC_ADMIN_KEY" \
  -G --data-urlencode "starting_at=2026-07-01T00:00:00Z" \
     --data-urlencode "bucket_width=1d" \
     --data-urlencode "group_by[]=model" \
     --data-urlencode "group_by[]=workspace_id" \
     --data-urlencode "group_by[]=service_tier" > usage.json

# 2. Read it before you send it. Counts and dimensions. No prompts, no completions.
jq '.data[0].results[0]' usage.json
{
  "model": "claude-opus-5",
  "uncached_input_tokens": 4000000,
  "cache_read_input_tokens": 180000000,
  "cache_creation": { "ephemeral_1h_input_tokens": 26000000, "ephemeral_5m_input_tokens": 0 },
  "output_tokens": 9000000,
  "service_tier": "standard"
}

There is no prompt text in it

The usage report is token counts, model names, workspaces and tiers. That is the whole payload. You can read every byte of the file before you decide to share it — and you should.

It is your data, from your vendor

We do not sit in your request path, hold your key, or ask you to trust our numbers over Anthropic's. The file comes from Anthropic's API to your disk.

What comes back

Your real cache-hit rate, your real cache-write TTL split, per-workspace attribution, and a dollar figure for each lever — computed from that file, with the arithmetic shown. Where a lever cannot be measured from an aggregate, we say so instead of estimating it.

One caveat we'd rather say first. An aggregate report has no per-request timing, so any lever that depends on the gap between consecutive turns — cache-write TTL right-sizing, above all — can be sized as exposure but not as a saving. Measuring that one needs request-level data. We will tell you which of your numbers is which.
